เก็บข้อมูลใน Google Sheets

ข้อมูลอยู่ใน Google Drive ของคุณ · ซิงก์ข้ามเครื่องอัตโนมัติ

เชื่อมต่อแล้ว
—
มีโค้ด Apps Script เวอร์ชันใหม่ — อัปเดตเพื่อให้ข้อมูล ผ่อนชำระ (จ่ายจริง/ค่าอะไร) และ เงินฝาก (ประเภท/ฝากต่อเดือน) ซิงก์ข้ามเครื่อง (ตอนนี้ส่วนที่ยังไม่รองรับเก็บไว้เฉพาะในเครื่องนี้)
วิธีอัปเดต: เปิดชีต → ส่วนขยาย → Apps Script → ลบโค้ดเดิม วางโค้ดใหม่ → บันทึก → ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → กดไอคอนดินสอ → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้ (URL เดิมใช้ได้ต่อ)
เปิดชีต ↗

เปิดลิงก์ที่คัดลอกบนเครื่องอื่น แอปจะเชื่อมกับชีตเดียวกันให้อัตโนมัติ (อย่าแชร์ลิงก์นี้ให้คนอื่น)

  1. สร้าง Google Sheets ใหม่ (ไฟล์จะอยู่ใน Google Drive ของคุณ)
    สร้างชีตใหม่ ↗
  2. ในชีต ไปที่ ส่วนขยาย → Apps Script ลบโค้ดเดิม วางโค้ดนี้ แล้วกดบันทึก
  3. กด ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ เลือก เว็บแอป ตั้ง “ผู้ที่มีสิทธิ์เข้าถึง” เป็น ทุกคน แล้วอนุญาตสิทธิ์ (ถ้าขึ้นคำเตือน กด ขั้นสูง → ไปที่โปรเจกต์)
  4. คัดลอก URL ของเว็บแอป (ลงท้ายด้วย /exec) มาวางด้านล่าง

ไม่เชื่อมต่อก็ใช้งานได้ตามปกติ ข้อมูลจะบันทึกไว้ในเครื่องนี้
